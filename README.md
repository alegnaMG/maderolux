# Maderolux

Web de Maderolux — maderoterapia y tratamientos estéticos a domicilio en Madrid.

## Stack

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · shadcn/ui · Vitest · pnpm

## Desarrollo

```bash
pnpm install
pnpm dev            # http://localhost:3000
pnpm lint
pnpm test
pnpm test:coverage
pnpm build
```

La hoja de ruta por fases está en [PLAN.md](PLAN.md).
